# Asset Credits

All assets are bundled locally in `assets/`.

## Images

Every event has its own illustration. They are original artwork created for
this project by [`tools/generate_event_images.py`](tools/generate_event_images.py)
(Python + Pillow); no third-party images are used.

| File | Event |
|---|---|
| `assets/images/flutter_workshop.png` | Flutter Workshop for Beginners |
| `assets/images/ai_panel.png` | AI and Society Panel |
| `assets/images/photography_exhibition.png` | Autumn Photography Exhibition |
| `assets/images/choir_concert.png` | Campus Choir Concert |
| `assets/images/basketball_final.png` | Inter-Faculty Basketball Final |
| `assets/images/campus_run.png` | Morning Campus Run (5K) |
| `assets/icon/app_icon.png`, `assets/icon/app_icon_foreground.png` | App icon |
